# v9.1.2 — Human takeover + contextual closing

HUMAN_LOCKED: Leo can take over one resolved branch by posting a manual comment whose text starts with `//`. The marker never receives an automatic reply. The exact `branchKey` is locked for the current 24-hour conversation window; other branches remain AUTO. Locked branches fail closed with `HUMAN_LOCKED`. If the marker cannot be mapped to a branch, no broad lock is guessed.

Contextual closing: the 3/3 safety budget is unchanged. Reply #3 remains the final automatic reply allowed by the budget, but DM is no longer forced. DM is suggested only when the context makes private continuation useful. If the user already sent a DM/application/catalog, acknowledge it without repeating the CTA.

Unchanged: Router, Graph, Memory, idempotency, cooldown, global cap, ambiguous publish hold, and fail-closed routing.
